# Aranhaverso

## Sobre o projeto

O Aranhaverso é um site informativo sobre o super-herói Homem-Aranha.
O objetivo é apresentar sua história, suas habilidades, curiosidades,
dados sobre filmes e formulários temáticos utilizando HTML sem CSS.

## Páginas do site

- `index.html` — página inicial.
- `sobre.html` — história, curiosidades e glossário.
- `dados.html` — tabela de filmes.
- `cadastro.html` — formulário de inscrição.
- `contato.html` — informações de contato e formulário de mensagem.

## Tecnologias utilizadas

- HTML5
- Git e GitHub
